# Master.crm 🚀

**نظام إدارة علاقات العملاء (CRM) الشامل للسوق المصري**

## 📋 نظرة عامة

Master.crm هو نظام إدارة علاقات العملاء والمشاريع المتقدم المصمم خصيصاً للسوق المصري. يجمع بين واجهة مستخدم احترافية وميزات متقدمة لإدارة العملاء والفواتير والفروع والموظفين.

## ✨ المميزات الرئيسية

- 🔒 **حماية أمنية برمز PIN**: نظام تسجيل دخول آمن برقم سري (117067)
- 🌍 **دعم ثنائي اللغة**: واجهة عربية وإنجليزية مع تحويل فوري
- 📱 **تصميم Responsive**: يعمل بكفاءة على جميع الأجهزة (ديسكتوب، تابلت، موبايل)
- 💾 **تخزين محلي**: حفظ البيانات في localStorage للعمل بدون خادم
- 📊 **لوحة تحكم متقدمة**: رسوم بيانية وإحصائيات فورية
- 👥 **إدارة العملاء**: إضافة وتعديل وحذف العملاء
- 🧾 **إدارة الفواتير**: نظام متطور لإصدار وتتبع الفواتير
- 🏢 **إدارة الفروع**: تنظيم الفروع والموظفين
- 🔐 **إدارة الصلاحيات**: نظام متقدم لإدارة الأدوار والصلاحيات
- 📥 **تصدير البيانات**: تحميل الفواتير بصيغة CSV
